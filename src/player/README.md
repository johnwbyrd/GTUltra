# Player - C Implementation

A readable, maintainable C rewrite of the GoatTracker music player for the Commodore 64.

## Overview

This is a C language implementation of the GoatTracker music player, originally written in 6510 assembly. The goal is to create code that is:

1. **Readable** - Well-structured with clear variable names and heavy documentation
2. **Maintainable** - Modular design with separated concerns
3. **Compatible** - Plays existing GoatTracker .sng files without modification
4. **Performant** - Optimized through clarity, runs at full speed on C64 hardware

**Target Compiler**: llvm-mos (LLVM-based compiler for 6502/65C02)

## Features

- **3-channel SID music playback** (1 SID chip, 3 voices)
- **16 effects**: Portamento, vibrato, filters, ADSR, tempo control, etc.
- **Wavetables**: Animated waveforms and pitch changes
- **Pulse tables**: Pulse width modulation (PWM)
- **Filter tables**: Automated filter sweeps
- **Sound effects**: Priority-based SFX with music override
- **Multi-song support**: Multiple songs in one file
- **Binary compatible**: Reads original GoatTracker .sng files

## Usage

### Basic Example

```c
#include "player.h"

// Music data (in ROM, generated by gt2reloc)
extern const MusicData my_song;

// Player state (in RAM)
static Player player;

// Initialize player
void init_music(void) {
    player_init(&player, &my_song, 0);  // Song 0
}

// Call from interrupt (50Hz PAL or 60Hz NTSC)
void __interrupt music_irq(void) {
    player_play(&player, &my_song);

    // Acknowledge interrupt
    VIC.raster_irq = 1;
}

int main(void) {
    init_music();

    // Set up raster interrupt at line 250
    VIC.raster_line = 250;
    VIC.ctrl1 &= 0x7F;
    VIC.irq_mask = 0x01;
    asm("cli");  // Enable interrupts

    // Main loop
    while (1) {
        // Game logic here
    }
}
```

### With Sound Effects

```c
// Define sound effect data in ROM
const uint8_t explosion_sfx[] = {
    0x09,       // Attack/Decay
    0xF0,       // Sustain/Release
    0x80,       // Pulse width
    0xC0, 0x80, // Note + waveform (noise)
    0xB0,       // Pitch down
    0xA0,       // Pitch down more
    0x00        // End
};

// Play sound effect on channel 0
void play_explosion(void) {
    player_play_sfx(&player, &my_song, 0, explosion_sfx);
}
```

### Volume Control

```c
// Set master volume (0-15)
player_set_master_volume(&player, 15);  // Full volume
player_set_master_volume(&player, 8);   // Half volume
player_set_master_volume(&player, 0);   // Mute
```

## API Reference

See `include/player.h` for complete API documentation.

### Core Functions

- `player_init()` - Initialize player with a song
- `player_play()` - Main playback routine (call every frame)
- `player_play_sfx()` - Play sound effect
- `player_set_master_volume()` - Set master volume

### Utility Functions

- `player_get_song_position()` - Get current order list position
- `player_get_pattern_number()` - Get current pattern number
- `player_is_sfx_playing()` - Check if SFX is active
- `player_stop_all_sfx()` - Stop all sound effects
